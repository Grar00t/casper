# التشغيل المحلي والتحقق

المسار الأساسي يحتاج Python 3.10+ وGCC أو Clang المتوافق مع GCC فقط.
على Windows استخدم MinGW-w64؛ لا يستخدم هذا المسار cl.exe أو Bash أو Actions.
وجود مسار Windows في الكود ليس إثباتًا بأنه اختبر على Windows.

```powershell
python scripts/build_native.py --smoke
python tools/casper_local_server.py
```

افتح http://127.0.0.1:8765. الواجهة عربية، وتستخدم مكتبة Python القياسية
وجسر Chronicle الموجود لتشغيل محرك C والتحقق من إيصالاته. ليست نموذج محادثة
عامًا: البحث حرفي، وفحص الدين محصور بالصيغ التي يدعمها Chronicle.
الإيصال يثبت سلامة البيانات والنتيجة، لا صدق الوقائع في العالم.

النصوص والإيصالات تبقى في build/local-chronicle أو مجلد --store-root.
الخادم أحادي المستخدم، مربوط بـ127.0.0.1 فقط، ويرفض Host/Origin غير المحلي.
لا تنشره على الإنترنت. لا يقدم مصادقة متعددة المستخدمين، ولا يحذف الأدلة تلقائيًا.
لا تُعرض نصوص المستخدم كـHTML؛ تعرض النتيجة كاملة عبر textContent.

```powershell
python scripts/verify_local.py
```

الفاحص يبني C ويشغل smoke واختبارات الجسر الأصلي والسامبلر وHTTP والمدرب.
يسجل نتائج كل خطوة وبصمتها في build/local-verification. لا يثبت اعتمادات
ولا يشغل خدمات خارجية أو GitHub Actions. خيارات إضافية:

```powershell
python scripts/verify_local.py --sanitize --chronicle --node
```

يتطلب --node تثبيت اعتمادات niyah_engine_local مسبقًا. تدقيق npm قد يستخدم
الشبكة للاستعلام عن الإرشادات؛ ليس برهان أمان كاملًا. لا تستخدم --node إن
كنت تريد تحققًا بلا شبكة. اختبار المدرب العددي يتخطى نفسه عند غياب PyTorch؛
نجاح الفاحص لا يحول الاختبار المتخطى إلى اختبار ناجح. راجع السجلات.
اختبارات HTTP تستخدم جسرًا وهميًا معلنًا؛ اختبار الجسر الأصلي منفصل ويحتاج
البرنامج المترجم. لا تعتبر هذه الدفعة إثبات اختبار متصفح أو Windows أو CUDA.

خدمة Node الاختيارية منفصلة عن هذه الواجهة. تعطيل محول نموذجها افتراضيًا
لا يجعلها خدمة بلا اتصالات ويب: مسار البحث فيها قد يصل إلى الشبكة.
تحديث Express وتقييد ربط خدمة Node وتنظيف الملفات غير المستخدمة ليست ضمن
هذه الدفعة. لم تحذف ملفات أو اختبارات أو توثيق قد يعتمد عليه المشروع.
